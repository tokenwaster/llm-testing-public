Maze Discovery — 24 Explorer Bots

A random perfect maze (21×21). Every bot starts knowing only its own cell and explores Tremaux/DFS-style: it walks into unknown passages, and on hitting a dead end (or a fully explored branch) it backtracks and marks that branch dead in its own memory, so no passage is walked more than twice. Each bot has a different seeded direction preference, so they fan out. The timer freezes when the LAST bot arrives.
