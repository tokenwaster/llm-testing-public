### Key rules:

- Only **SETTLED** transactions count toward the settled balance.
- **PENDING** transactions never count.
- A **VOID id** cancels that transaction *entirely* (i.e., if it was previously applied, undo its effect).
- An **AMEND id amount** replaces the *amount* of that transaction — but only if that transaction is **SETTLED**, and not already voided at that point. The amendment applies to the *current effective amount* of that transaction (so later amendments override earlier ones for the same ID), and the amended amount is used in computing balances.

- Process entries **strictly in order** — so when we encounter a TXN, VOID, or AMEND, apply it to our internal state.
