Capable is how many of the fleet clear the bar — when it reads 35/35 the lane is saturated and a score ranking is meaningless (they all tie), so the real answer is the cheapest that works: you do not need a frontier model for that job. When Capable is low, the lane genuinely separates and Best is the answer. Cheapest counts only durable costs — a local model's measured electricity, or a genuinely paid API. OpenRouter's promotional :free variants are listed beneath it as “free now” and marked ⏳: their $0 is a true record of what that run was billed, but it is a promotion, not a price you can plan on (why this matters →). Filter to the models you can actually run. Top quality = highest category score (ties share the crown). Value pick = fastest generator among models scoring at least the capable threshold — the rational choice when latency or bulk throughput matters more than the last few points. Thresholds live in directives.yaml (excellent ≥ 0.95, capable ≥ 0.85, value pick ≥ 120 tok/s) — edit and the classification updates on the next report regeneration.

Token counts come from each provider's usage field and are only comparable within a model family (tokenizers differ) — tok/s and cost are the fair cross-model axes. Gen tok/s excludes time-to-first-token. Wall times include every retry. A ✓ after a cost means it is the gateway's actual billed amount (OpenRouter usage accounting) rather than yaml list pricing; "via <host>" names the upstream provider that actually served the requests.
Claude has no cost figure here, on purpose. Every Claude model is measured through the Claude Code CLI, which runs on a subscription — there is no per-token price to report, so any number would be invented. Every other row is what the provider billed, or list pricing on real token counts. We tried publishing a derived API-equivalent and measurement refuted it twice: the CLI sends its own instructions, reads its own files and carries its own conversation, so it consumed 16× more input per turn than the same model doing the same task through an API — a different agent, not a fixed overhead, and nothing you can subtract. Claude cost lands here when the full suite has been run through the API, not before.
